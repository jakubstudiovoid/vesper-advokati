# Vesper — prémiový web advokátní kanceláře

Fiktivní ateliérový web pražské kanceláře **Vesper**. Dark-first minimalismus, silná typografie, úzká paleta a kompletní struktura webu 2026.

Živá stránka po zapnutí GitHub Pages:

[https://jakubstudiovoid.github.io/vesper-advokati/](https://jakubstudiovoid.github.io/vesper-advokati/)

## Informační architektura

- Úvod — slib, agenda, přístup, vybraná práce, tým, CTA
- Služby — korporát, spory, nemovitosti, majetek, compliance, smlouvy
- Přístup — čtyři kroky vedení mandátu
- Kancelář — vznik, principy, místo
- Tým — partneři a právníci
- Kontakt — formulář, adresa, identifikace
- Ochrana osobních údajů
- Cookies s reálnou volbou

## Vizuální směr

- Pozadí `#0A0A09`, inkoust slonoviny, akcent šampaňského zlata
- Nadpisy Cormorant Garamond, text Manrope
- Pomalé reveal a hover, žádný vizuální šum
- Tmavý režim jako základ, světlý režim přepínačem

## Technika

Statický HTML / CSS / JS. Bez frameworku, bez trackerů.
Formulář je ukázkový a data na server neodesílá.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.
